Genetic mating engine

Prototype pairing heuristic inspired by AlloMate's multi-trait merit, kinship constraints and sire–dam allocation workflow. It is not a port of the original R optimizer or a certified genetic evaluation.

Kinship is not calculated reliably from incomplete parent IDs. Unknown relatedness is flagged, not assumed safe. The 6.25% inbreeding rule applies to the animal's inbreeding coefficient; pair kinship is a separate quantity.

SNP / genomic sample analysis

Import a CSV genotype table or SNP summary. This app can count marker calls and missingness, and summarize numeric trait columns if present. It does not infer genomic breeding values, disease risk, or ancestry from arbitrary SNPs without a validated reference panel, marker map, allele coding, and approved method.

Genotype file format guidance

Supported basic input: CSV/TSV with one marker per row (e.g. Marker,Genotype) or samples as columns. The prototype counts rows and common missing-call tokens. It does not validate strand, genome build, allele orientation, imputation, or SNP quality thresholds.

Reports, import and backup

Export a full JSON backup to preserve records and uploaded images. Use CSV exports for spreadsheet analysis. Data remains in the current browser profile unless you export or move it.

Important: local browser storage is not cloud sync. It may be removed if browser data is cleared, the device is reset, or storage is evicted. Keep encrypted backups somewhere safe. Avoid storing identifiable farmer or clinical data on shared devices.
